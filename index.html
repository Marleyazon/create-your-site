Gestion des Pages

Le format choisi est exactement celui du site publie.
Chaque element peut aussi avoir sa propre police dans le panneau "Modifier".
Selectionne un texte puis remplis ses traductions dans "Modifier".
Dans l'editeur, deplace la colonne par sa barre de titre ; le corps se fait defiler normalement.
Detourage et suppression d'une couleur : selectionne l'image puis va dans "Modifier".
La video se lit dans la page, sans ouvrir YouTube. La lecture auto demarre en mode muet (regle des navigateurs).
Chaque message est envoye en POST JSON {site, page, nom, email, message, date} et garde une copie dans ta boite locale.
⠿ Attrape et glisse ce bloc jusque dans la liste "Onglet Script" ci-dessous
Ton script est ajoute a la liste ci-dessous. Le code Lua s'affiche comme du texte (Roblox uniquement, pas de moteur d'execution dans un navigateur). Le code JavaScript s'execute pour de vrai sur le site publie/exporte, sans rien afficher aux visiteurs — utilise Site.get("NomDeLElement") pour recuperer un element par le nom que tu lui donnes dans "Modifier" (nom jamais visible sur le site, comme dans Roblox).
Astuce souris : clique-glisse sur une zone vide du canevas pour selectionner plusieurs elements a la fois (Ctrl+C / Ctrl+V pour les copier-coller ensemble).
Raccourcis : Ctrl+Z annuler · Ctrl+W retablir · Ctrl+C copier · Ctrl+V coller (meme position, meme sur une autre page) · Ctrl+A tout selectionner · Ctrl+D dupliquer · Suppr effacer.
